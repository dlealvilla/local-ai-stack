## What 2.3 proves locally

Accelerator hardware can be observed through a vendor-neutral
capability. NVIDIA discrete GPUs, AMD Instinct devices, and Apple
Silicon GPUs are representable without forcing one vendor's shape onto
the others. Missing NVIDIA or AMD tooling is unavailable, not a
measured zero-GPU rack. Unified/APU memory is not invented as dedicated
VRAM.

A later NVIDIA+AMD wheel does not inherit the historical NVIDIA physical
PASS recorded on SHA `351cee81…`. That PASS remains valid only for that
exact candidate. Apple physical acceptance remains deferred.

Physical coverage for SHA `eaee5c98…` is recorded in
[M2-2.3-NVIDIA-AMD-COVERAGE.md](M2-2.3-NVIDIA-AMD-COVERAGE.md):
A40, MI300X, and RTX PRO 4500 Blackwell. Estimated weighted
product-support proxy ≈ 0.85. Not a universal GPU claim.

## Core vs adapter

`AcceleratorObservation`, `AcceleratorDevice`,
`AcceleratorProviderReport`, and `AcceleratorObserver` live in
`machi.discover`. `NativeAcceleratorObserver` selects applicable
providers in order NVIDIA, AMD, Apple and concatenates generic devices.
`NvidiaAcceleratorProvider` owns `nvidia-smi` CSV parsing.
`AmdAcceleratorProvider` owns `amd-smi` JSON parsing.
`AppleAcceleratorProvider` owns `system_profiler` JSON parsing.
Composition wires only the native observer. Provider-local inspect
failures become that provider's `failed` report.

## AMD JSON shapes

Supported structured `amd-smi` JSON (ROCm 6.x / Instinct evidence):

- top-level array of GPU/CPU objects from `amd-smi list --json` and
  `amd-smi static --asic --vram --bus --json`
- object envelopes keyed `gpu`, `gpu_data`, `gpus`, `gpu_list`, or
  `devices`
- VRAM size as `{value, unit}` with `MB`/`MiB` (binary 2^20) or a bare
  integer treated as MiB

Intentionally rejected: human-readable tables, `rocm-smi`, sysfs/DRM,
Python `amdsmi`, unknown units such as `KB`, recursive VRAM hunting,
and treating a memory number as proof of discrete topology.

MI300X / HBM or Instinct (non-MI300A) → `discrete_gpu` + dedicated
bytes. MI300A / APU / DDR-class type → `integrated_gpu` + unified +
unresolved dedicated total.

## Memory topology

Generic fact, not a VRAM synonym:

- `discrete` — dedicated accelerator memory may be reported in bytes
- `unified` — shared with system memory; dedicated total stays Unresolved
- unknown stays Unresolved, never `0`

## Provider inspection status

Separate from `ObservationStatus` (shared with OS/arch and memory):

- `observed` — inspection succeeded, `0..N` devices (empty success is allowed)
- `not_applicable` — host facts make this provider meaningless
- `unavailable` — tool/API missing
- `unsupported` — reserved
- `failed` — non-zero exit, timeout, or malformed output

Overall observation status is `normalized` when at least one provider
observed, else `unobserved`.

## REUSED CONCEPTS

- Adapters observe; core owns normalized meaning.
- Unknown is not zero.
- Observation is not mutation and not admission.
- Kultrun: missing `nvidia-smi` is unavailable, not zero GPUs.
- Kultrun: `memory.total` MiB converts as `n * 1024 * 1024`.
- Kultrun: injected CSV replay for deterministic tests.
- Kultrun: machine-readable `--query-gpu` / `--format=csv,noheader,nounits`.

## SELECTIVELY REUSED CODE

None copied. Kultrun `NvidiaProvider` was read as evidence only.

## REJECTED LEGACY PATTERNS

- PCI bus as required generic identity.
- Silently skipping malformed `nvidia-smi` rows.
- Naive `str.split(",")` (breaks quoted model names).
- hwloc vs NVIDIA assignment authority / `reports_accelerator_assignment`.
- Driver version as a generic Discover field.
- Treating NVIDIA as the Accelerator Discovery model.
- Copying `hw.memsize` / `physical_memory` into Apple GPU memory.
- `pynvml`, CUDA, torch as base-wheel dependencies.
- Collapsing unavailable / not-applicable / failed into `0` devices.
- Reducing multi-GPU hosts to a primary GPU.
- Summing VRAM in Discover.

## ENHANCEMENTS MADE

- Vendor-neutral `AcceleratorObservation` with `0..N` devices.
- `ProviderInspectionStatus` so unavailable is not a device count.
- Unified topology forbids a normalized dedicated total.
- `csv` module parsing for NVIDIA quoting.
- Apple identity from model slug, not PCI.
- AMD `amd-smi` JSON provider with discrete MI300X bytes and
  MI300A/APU unresolved dedicated memory.
- Intel remains vocabulary only and is not wired.
- Architecture tests isolate domain, NVIDIA I/O, AMD I/O, Apple I/O,
  Intel exclusion, and composition.

## Deferred

- Intel provider.
- Apple Silicon physical proof.
- NVIDIA+AMD physical proof of this candidate.
- XCP / partition hierarchy, SR-IOV, `rocm-smi`, sysfs/DRM fallback.
- Broader Radeon/iGPU coverage.
- Horizontal shapes (no GPU, constrained visibility) beyond fixtures.
- HostProfile aggregation.
- Capacity safe/available VRAM.
