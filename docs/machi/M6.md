# M6 — Model (Tier 2)

**Primary:** `6` Model  
**Does not:** load weights, start vLLM, serve, choose serving
parameters, admit resources, benchmark quality, convert, quantize,
or fine-tune

Model answers which artifacts exist or can be acquired, what they
are, whether they fit this Foundation and host, what they
approximately require, and whether Machi can store and reuse them.
`STORED` is not `LOADED` and not `RUNNING`.

Sources are explicit. The hub adapter resolves one named repository
to an immutable commit before acquire. A branch or tag is the
request, not the stored identity. Local import copies a directory
into the warehouse and does not treat the external path as owned.
Symlinks, special files, and hard links are refused. The generic
model package does not import the hub client. Local import does not
need a network.

Inspection may read config, tokenizer metadata, and a safetensors
index. It does not download multi-gigabyte weights and does not
execute repository Python. `trust_remote_code` stays refused. A
config that asks for repository code is `blocked_by_policy` /
`remote_code_required`.

Compatibility is not architecture recognition. A candidate is
`compatible` only when cheap policy checks pass and a finite predicate
from the verified generation supports the derived attention shape and
dtype. Vacuous predicates, including a backend that accepts every head
size, are not support. Unknown structure stays unresolved. The
architecture registry remains a coarse prefilter. The predicate query
reads the installed generation and does not load weights.

`model.available` version 1 is still the evaluated snapshot. It is not
a deployable set. `model.deployable` version 1 is the available set:
runtime-qualified and feasible against one current capacity snapshot.
`QualificationQueue` orders feasible candidates for the next proof. It
is not a recommendation. `ModelSelector` may choose only from the
deployable set. Plan refuses a recipe outside the qualification
envelope. Reuse also requires the execution-environment fingerprint.
`hardware_class` still groups a campaign. It does not by itself
make one accelerator's pass cover another. Evidence recorded before
that fingerprint does not cover a new deployment.

Empirical execution is a protocol. Local tests use a fake probe. No
external model is runtime-qualified on hardware (`M-6-03`). One
deterministic formula, refined with a vLLM workspace floor, is the
estimator. llmfit and Accelerate are not called.

`ModelRequirement` is artifact bytes plus a static weight baseline.
It is not serving VRAM and not a deployment requirement. Parameter
count is recorded only from metadata, not from a name such as `7B`.
Context length is the model's declared maximum, not a serving choice.
License identifiers are captured. Commercial use stays unknown or
review unless the identifier is one of a small declared set. A
license block does not rewrite technical compatibility.

Acquire checks SAFE storage before copy or download. Files land in
owned staging, are hashed with SHA-256, and are promoted into
`models/warehouse/<artifact id>/` with `.machi-model.json`. A partial
tree is not an artifact. An exact verified artifact is reused. A
hash mismatch is an integrity failure and is not rewritten. Tokens
are never stored in definitions, manifests, or events.

`AvailableModels` is a snapshot of a bounded candidate set against
one Foundation and one Capacity snapshot. It is not a crawl of the
hub. `ModelSelection` names a model for a later plan. It does not
reserve, load, or start anything.

`MEANINGFUL_SETTINGS_REMAIN_TYPED_AND_INSPECTABLE=YES`.

Default policy: explicit sources, hub and local enabled, immutable
revision, remote code refused, copy into the warehouse, SHA-256,
surface unknown licenses, inspect does not fetch weights.

Tier-3 catalog search, conversion, benchmarking, other providers,
and training are `M-6-01`. AMD qualification remains `M-5-AMD-01`.

Native/vLLM and Ollama keep separate model catalogs. The warehouse
`ModelArtifact` is authoritative for the native macropath. An Ollama
model is addressed by its provider digest; the tag is a display name.
Ollama's load and scheduler result is the authoritative qualification
for that macropath. Machi also records a non-authoritative shadow
estimate from public facts and the current SAFE envelope. The
comparison record `model.qualification_comparison` version 1 is local
operational analytics. It does not veto Ollama, merge the catalogs, or
retune estimation policy in Stage 1. Ollama `size_vram` is
runtime-reported loaded VRAM, not an external peak. Ollama residency
and eviction under a long-lived Serve reservation remain
`M-6-OLLAMA-01`.

Physical acceptance is recorded in [M6-PHYSICAL.md](M6-PHYSICAL.md).
The closure candidate was inspected on a qualified NVIDIA A40. It
resolved `main` to commit `9fb191250dd56d0ba7ec9785a025ed29c03d5998`,
stored 6,477,074 bytes, reused that artifact, copied a local import
without owning the external tree, and refused an unrecognized
architecture. No weights were loaded and no server was started.
