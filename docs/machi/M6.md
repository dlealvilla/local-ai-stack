# M6 — Model (Tier 2)

**Primary:** `6` Model  
**Does not:** load weights, start vLLM, serve, choose serving
parameters, admit resources, benchmark quality, convert, quantize,
or fine-tune

Model answers which artifacts exist or can be acquired, what they
are, whether they fit this Foundation and host, what they
approximately require, and whether Machi can store and reuse them.
`STORED` is not `LOADED` and not `RUNNING`.

Sources are explicit. The hub adapter resolves one named repository
to an immutable commit before acquire. A branch or tag is the
request, not the stored identity. Local import copies a directory
into the warehouse and does not treat the external path as owned.
Symlinks, special files, and hard links are refused. The generic
model package does not import the hub client. Local import does not
need a network.

Inspection may read config, tokenizer metadata, and a safetensors
index. It does not download multi-gigabyte weights and does not
execute repository Python. `trust_remote_code` stays refused. A
config that asks for repository code is `blocked_by_policy` /
`remote_code_required`.

Compatibility is several facts, not one boolean: architecture
recognized by the installed engine, safetensors weights, published
quantization the engine lists, remote-code policy, SAFE storage, and
a static weight baseline. The architecture set comes from a short
query of the managed interpreter. That query does not load weights
and does not start the server. Unknown storage or planning-dependent
memory stays conditional. A deferred Foundation provider, including
AMD under `M-5-AMD-01`, is a qualification caveat, not
"unsupported" and not production-validated.

`ModelRequirement` is artifact bytes plus a static weight baseline.
It is not serving VRAM and not a deployment requirement. Parameter
count is recorded only from metadata, not from a name such as `7B`.
Context length is the model's declared maximum, not a serving choice.
License identifiers are captured. Commercial use stays unknown or
review unless the identifier is one of a small declared set. A
license block does not rewrite technical compatibility.

Acquire checks SAFE storage before copy or download. Files land in
owned staging, are hashed with SHA-256, and are promoted into
`models/warehouse/<artifact id>/` with `.machi-model.json`. A partial
tree is not an artifact. An exact verified artifact is reused. A
hash mismatch is an integrity failure and is not rewritten. Tokens
are never stored in definitions, manifests, or events.

`AvailableModels` is a snapshot of a bounded candidate set against
one Foundation and one Capacity snapshot. It is not a crawl of the
hub. `ModelSelection` names a model for a later plan. It does not
reserve, load, or start anything.

`MEANINGFUL_SETTINGS_REMAIN_TYPED_AND_INSPECTABLE=YES`.

Default policy: explicit sources, hub and local enabled, immutable
revision, remote code refused, copy into the warehouse, SHA-256,
surface unknown licenses, inspect does not fetch weights.

Tier-3 catalog search, conversion, benchmarking, other providers,
and training are `M-6-01`. Physical NVIDIA acceptance is required
before this block closes. AMD qualification remains `M-5-AMD-01`.
