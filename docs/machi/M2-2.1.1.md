# M2 Discover — 2.1.1 OS/arch adapter

**Primary:** `2.1.1` OS/arch adapter  
**Consumes:** Kernel Clock / Unresolved / EventRecord; optional M1
InstallId and InstallRunId from composition  
**Not in this increment:** HostId, HostProfile, memory, NVIDIA,
fixtures, mounts, compatibility, provider detection  
**Event:** `discover.os_arch.observed` (`public_ops`; `host_id`
unresolved; Install correlation only when composition supplies it)  
**CLI:** `machi discover os-arch [--state-root PATH] [--store-dir DIR] [--journal-dir DIR]`  
**Record:** `OSArchitectureObservation` (`os_architecture_observation@1`)  
**Persistence:** event only; no Store entity

This is not a substitute for [ARCHITECTURE.md](ARCHITECTURE.md).
It records what 2.1.1 reused from Kultrun and what it refused.

## What 2.1.1 proves

This host has an observed OS family and CPU architecture, normalized
through a replaceable adapter, with raw evidence retained.

## What 2.1.1 does not prove

That the host is supported. That it has enough memory or a GPU. That
a unique HostId exists. That Discover is complete.

**HostId created here: NO.**  
**HostProfile created here: NO.**  
**Support decision produced: NO.**

## Core vs adapter

`OSArchitectureObservation` and `normalize_os_architecture` live in
`machi.discover`. `NativeOSArchitectureObserver` lives in
`machi.adapters.discover` and is the only module that calls
`platform.system` / `platform.machine`. Composition selects the
adapter.

## REUSED CONCEPTS

- Adapters observe; core owns normalized meaning.
- Architecture aliases: `x86_64`/`amd64` → `x86_64`; `aarch64`/`arm64`
  → `arm64`.
- OS family is the branching key; Darwin maps to `macos`.
- Unknown is not defaulted to a supported value.
- Observation is not mutation and not admission.

## SELECTIVELY REUSED CODE

None copied. Kultrun `NativeLinuxProvider` and `Architecture` were
read as evidence only.

## REJECTED LEGACY PATTERNS

- `HostCapabilities` / `OperatingEnvironment` mega-contract in this
  increment.
- `Architecture.UNKNOWN` enum member that looks like a third ISA.
- Provider plugin manager / path-bag observations.
- Minting HostId during OS/arch detect (Kultrun `discover()`).
- Hostname, `/etc/os-release`, `/proc/meminfo`, mounts, container
  detection, subprocess `uname`.
- Treating unrecognized OS as Linux because `/proc` exists.

## ENHANCEMENTS MADE

- Explicit `ObservationStatus`: normalized / unrecognized / unobserved.
- Unresolved uses `unsupported` vs `not_measured`, not a fake arch.
- Raw platform strings retained beside normalized fields.
- Event privacy `public_ops` per telemetry policy for OS family.
- Install correlation supplied by composition, not by the adapter.
