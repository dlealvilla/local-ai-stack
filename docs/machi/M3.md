# M3 — Steward (Tier 2)

**Primary:** `3` Steward  
**Component:** ownership, occupancy, and reclaimability  
**Does not:** delete, crawl mounts, infer ownership from names, or
compute `SAFE_STORAGE_BYTES`

Verified ownership is a local `.machi-owner.json` whose fingerprint
matches the root, plus a registry record with the same marker id and
fingerprint. InstallId mismatch, a copied marker, malformed evidence,
and a legacy Kultrun marker fail closed. Unknown is not reclaimable.

An obsolete, unprotected, verified root is a reclaim **candidate**.
The file stays. Active and rollback generations stay protected.

Occupancy bytes are measured only for verified roots. Symlinks are not
followed. A different device is not entered. Hard links count once.
An unreadable child leaves the size `Unresolved`.

Optional `MountObservation` from 2.4 supplies mount and backing
identity. Steward does not rediscover mounts.

`MEANINGFUL_SETTINGS_REMAIN_TYPED_AND_INSPECTABLE=YES`.

Defaults preserve unknown, conflict, and legacy state. Destructive
authorization is false.

Tier 3 cleanup is `S-3-01` in `docs/DEBT.md`.
