# M1 Install — 1.2.1 StateRootBinder

**Primary:** `1.2.1` StateRootBinder  
**Not in this increment:** `1.1.1`, `1.3.1`, `1.4.1`  
**Event:** `install.state_root.bound` (`restricted`)  
**CLI:** `machi install bind-root [--state-root PATH] [--journal-dir DIR]`

This is not a substitute for [ARCHITECTURE.md](ARCHITECTURE.md).
It records what 1.2.1 reused from Kultrun and what it refused.

## REUSED CONCEPTS

- One environment override, resolved in the composition root, handed
  down. Domains do not read `os.environ`.
- Blank or whitespace `MACHI_STATE_ROOT` is not a configuration
  (Kultrun: blank `KULTRUN_STATE_ROOT` would otherwise bind `/`).
- `expanduser().resolve()` once; the stored path is absolute and does
  not follow a later working-directory change (K-20).
- Installed artifacts that fall through to the platform default warn
  on stderr; source checkouts stay quiet.
- Distinguish “the directory exists” from “Machi owns this tree”.

## SELECTIVELY REUSED CODE

None copied. Kultrun’s `PlatformSettings.state_root` default
(`./.state`), `nearby_state_roots`, `.kultrun-owner.json` writer, and
`/var/lib/kultrun` convention were read as evidence only.

## REJECTED LEGACY PATTERNS

- Cwd-relative `./.state` as the product default.
- `/var/lib/kultrun` as the required or silent default (needs root;
  claims Kultrun).
- Sibling scan (`nearby_state_roots`).
- Writing `.kultrun-owner.json` or a Machi owner marker (that is 1.3.1).
- Creating `models/`, `runtimes/`, FileStore layout.
- Treating `KULTRUN_STATE_ROOT` as a Machi override.
- Putting the absolute path on a `public_ops` event.
- Emitting `install.bound` before InstallRun exists.

## ENHANCEMENTS MADE

- Operator contract (`StateRootBinding`) includes the path; the Kernel
  event payload carries only a SHA-256 fingerprint of that path.
- Privacy `restricted` (local Admin, not vendor).
- Platform default is `~/.local/state/machi` (user-local, cwd-stable,
  no root required). `XDG_STATE_HOME` is not a second authority.
- Refuse filesystem root, `/var/lib/kultrun`, and trees that already
  contain `.kultrun-owner.json`.
- Binder is Kernel-neutral: it does not import the journal adapter.
  Composition injects `<root>/journal` after bind.
