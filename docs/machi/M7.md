# M7 — Plan (Tier 2, local)

**Primary:** `7` Plan  
**Does not:** reserve resources, provision Foundation, acquire a
model, load weights, or start vLLM

Plan answers what serving configuration Machi should ask Admit to
consider. The answer is one immutable `DeploymentConfiguration` and
one `ResourceRequest`. The request is not permission to run.

Repository components stay `7.1` Compose, `7.2` Generation
(CURRENT versus STALE), and `7.3` Recipe. The recipe adapter is
vLLM only. Other planners are `M-7-01`.

A plan requires a verified stored artifact, a Foundation generation
in `READY`, a vLLM capability whose import and entrypoint were
verified, provider qualification `qualified`, and resolved SAFE
host and accelerator bytes. `conditionally_compatible` stays
unresolved. An unqualified foundation is refused by that
qualification state. There is no vendor-name branch.

The single-accelerator policy is `accelerator_count = 1` and
`tensor_parallel_size = 1`. Asking for more accelerators is
`multi_accelerator_planning_not_implemented`.

Serving context is `min(declared, 4096)` unless a bounded request
asks for less, and never more than the declaration or 32768.
Concurrency defaults to 4 and is bounded by 1..16.
`gpu_memory_utilization` is `0.90`, meaning a fraction of the
admitted SAFE budget, not a measured VRAM total. Remote code stays
refused. The artifact is cited by id, not by a cache path.

The accelerator memory request is that device's SAFE bytes. Host
memory is the snapshot's SAFE host bytes. Raw physical totals are
not used. Static weights above the chosen SAFE budget refuse the
plan. Admit still decides whether to reserve.

Policy version is `m7.plan.1`. The same inputs produce the same
fingerprint. A changed model, artifact, foundation, capacity,
policy, or preference produces a new plan and leaves the old one
unchanged.
