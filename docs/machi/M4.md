# M4 — Capacity (Tier 2)

**Primary:** `4` Capacity  
**Includes:** bounded Storage Sonar  
**Does not:** admit a workload, tune vLLM, place models, or delete
reclaim candidates

SAFE planning bytes are the smallest trusted hard bound minus an
explicit reserve. Reported filesystem available bytes, a specialist
entitlement, a Sonar contradiction, and an administrator ceiling stay
separate. A larger Sonar write does not raise the reported ceiling.
There is no ±10% agreement rule.

RAM, execution limits, per-device accelerator memory, and storage are
not added together. Two GPUs are two rows. Unified memory is not a
second VRAM pool. Mounts that share a backing id are one domain.

Default `sonar.writes` is `disabled`. A bounded run must opt in, stay
under `sonar.max_tier_bytes`, and leave `storage.reserve_bytes`
untouched. The probe file is `.machi-capacity-sonar-*`, created
exclusively, filled with real bytes, and removed afterward.

No live quota specialist is implemented. A `SpecialistBound` may be
supplied when a reader has actually produced one. Otherwise Sonar is
the empirical fallback for overlay, network, unknown, and
advertised-but-unread quota.

`MEANINGFUL_SETTINGS_REMAIN_TYPED_AND_INSPECTABLE=YES`.

Tier-3 specialists and optimizers are `M-4-01` and `M-4-02`.
